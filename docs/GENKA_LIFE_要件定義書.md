## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロダクト名（仮） | GENKA LIFE（原価ライフ） |
| コンセプト | プロの原価管理を、家計にゲーム感覚で応用するパーソナルファイナンスアプリ |
| 前身プロジェクト | Smart Kitchen Logistics v2（厨房向け原価管理システム） |
| 開発目的 | 1 RaiseTechサービス開発コンテスト出品 2 IT転職ポートフォリオとしての活用 |
| GitHub | https://github.com/Yusuke2000-hub/Smart-Kitchen-Logistics-v2 |

**なぜ「厨房」から「家計」へ？**
Smart Kitchen Logisticsで培った「原価率管理」のロジックは、実は家計管理と構造が同じです。

- 厨房の原価率　＝　食材費 / 売上
- 家計の生活防衛力　＝　支出 / 収入

現役調理師として原価率74.5%を実務で管理してきた経験を、誰もが当事者になれる「家計」という題材に転用することで、専門性の高さと一般性の両方を両立させます。

- 現役調理師（老人ホーム厨房店長）、原価率74.5%管理の実務経験あり

差別化ポイント：多くの家計簿アプリ・ポートフォリオ作品は「便利な記録ツール」止まりですが、本プロダクトはプロの原価管理という専門的な視点を家計に持ち込む点、そして専門的すぎる題材（B2B厨房システム）を一般消費者向けに汎用化する設計力を示せる点が強みです。

## 5. 機能要件（MVP：今回のスコープ）

### 5.1 家計管理コア
- 支出登録（費目：食費／光熱費、金額、日付）
- 収入登録（月次）
- 生活防衛力（支出÷収入）の自動計算
- 目標比率とのギャップ表示、超過時のアラート

### 5.2 ゲーム化要素
- レベル／XP：目標内に収まった月・週にXP付与、レベルアップ演出
- 週間チャレンジ：外食費削減など小さな目標の自動提案・達成判定
- バッジ：連続達成・特定費目の削減達成などの実績表示
- ダッシュボードでの防衛力ゲージ表示（グラフ）
- メダル制度：週間チャレンジ達成でメダル獲得、未達成で没収（週次リセット）
- 選択式コーチキャラクター（2〜3種類から選択）
  - 種類例：熱血コーチ / 毒舌ライバル / 無口な師匠
  - 達成時・未達成時にそれぞれ異なるメッセージを表示
- 進化キャラ（SVGオリジナル）：メダル数に応じてキャラクターが段階的に進化
  - 例：ひよこ → ニワトリ → 黄金のニワトリ

### 5.3 今回のスコープ外
- 家族のタスク管理
- 個人メモ機能
- 運動量トラッキング
- AIによる「ねぎらい日記」機能
- ミニゲーム的なゲームプレイ操作（進化演出のみ実装、ゲーム性は含まない）

## 7. 画面設計

| 番号 | 画面名 | URL | 主な内容 |
|---|---|---|---|
| ① | スタート画面（タイトル画面） | `/` | ロゴ・キャッチコピー・レベル／生活防衛力・ミッション開始ボタン |
| ② | ダッシュボード画面 | `/dashboard` | 生活防衛力ゲージ・今月の総支出・費目別支出テーブル |
| ③ | 支出登録画面 | `/expenses/save` | 費目・金額・日付の入力フォーム（現在はサンプルデータ登録） |
| ④ | 支出一覧画面 | `/expenses` | 登録済み支出の一覧表示（JSON） |

### ①スタート画面（タイトル画面）詳細

- **ロゴ**：「COSTLY」大文字タイトルテキスト（アプリ名称）
- **キャッチコピー**：「今日も、家計を守る。」
- **現在のステータス**：レベル（Lv.1 ※初期固定）と生活防衛力（%）の簡易表示
- **ミッション開始ボタン**：押下でダッシュボード画面（`/dashboard`）へ遷移
- デザインはダッシュボード画面と統一（Tailwind CSS）
