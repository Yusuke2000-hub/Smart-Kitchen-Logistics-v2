# COSTLY（コストリー）
〜調理師の原価管理スキルを、誰でも楽しめる家計簿ゲームに〜

## 📋 プロジェクト概要

COSTLYは、**「支出 ÷ 収入」で算出する生活防衛力**を軸にした、ゲーミフィケーション型の家計簿Webアプリです。

高齢者施設厨房の現場で実践してきた「食材原価率管理」の考え方（売上に対する原価の割合を継続的に把握・改善する手法）を、誰の家計にも当てはまる形に落とし込みました。単なる支出記録ではなく、**週次チャレンジ・メダル獲得・キャラクター成長・コーチとの対話**を通じて、続けたくなる家計管理を目指しています。

RaiseTechサービス開発コンテスト提出用ポートフォリオとして開発しています。

## 🔄 開発の経緯

本プロジェクトは、当初「Smart Kitchen Logistics（厨房DXシステム）」として、高齢者施設厨房の業務効率化（喫食数管理・原価率計算・多言語対応）を目的にスタートしました。

開発を進める中で、**「原価率管理」という専門的なスキルこそが、実は家計管理という誰もが抱える身近な課題に応用できるのではないか**という気づきを得て、対象をB2B（施設向け）からB2C（個人の家計向け）へとピボットしました。

現場で培った「数字を継続的に追いかけ、改善する力」を、専門知識がなくても楽しく実践できるアプリとして再構築したのがCOSTLYです。

## ✨ 主な機能

### 基本機能
- 支出登録（費目・金額・日付、8カテゴリ対応）
- ダッシュボード（費目別支出一覧、月次合計表示）
- 支出削除（確認ダイアログ付き）

### チャレンジ機能
- 生活防衛力（支出 ÷ 収入 × 100）の自動計算・判定
- 目標値（70%）に対する達成／未達成のリアルタイム表示
- プログレスバーによる視覚的な進捗確認

### ゲーミフィケーション要素
- **週次メダルシステム**：チャレンジ達成で週1個メダル獲得（週次で重複防止）
- **キャラクター進化**：メダル数に応じてキャラクターが成長（ひよこ → にわとり → 金のにわとり）
- **コーチ選択機能**：3種類のコーチから好きなタイプを選択可能
  - 🔥 熱血コーチ：達成/未達成をストレートに鼓舞するタイプ
  - 😏 毒舌ライバル：あえて厳しい言葉で発奮させるタイプ
  - 🍵 癒しのメンター：優しく寄り添い後押しするタイプ
- 選んだコーチのアイコン・セリフが達成状況に応じて動的に切り替わる

## 🚀 実行方法

```bash
# リポジトリをクローン
git clone https://github.com/Yusuke2000-hub/Smart-Kitchen-Logistics-v2.git
cd Smart-Kitchen-Logistics-v2

# ブランチを切り替え
git checkout genka-life-pivot

# JAVA_HOME設定（初回のみ、Windows PowerShell例）
. .\setup-env.ps1

# アプリケーション起動
.\gradlew.bat bootRun
```

起動後、ブラウザで `http://localhost:8080` にアクセスしてください。

## 📅 今後の展望

現時点では月収を固定値として扱っていますが、より実用的な家計管理ツールとするために、以下の機能拡張を予定しています。

- **収入入力機能**：月収を可変にし、実際の収支に基づいた防衛力計算を実現
- **月次・年次データ管理**：月ごと・年ごとの支出推移をグラフで可視化
- **過去データに基づく支出予測**：蓄積したデータから、翌月の支出傾向を推定する機能

これらは、現場での「原価率を継続的に追いかけ、先を見通す」という実務経験をさらに反映させていく方向性として構想しています。
